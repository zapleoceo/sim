## Подтверждённый бриф
Пользователь описал:
> Будут разные персонажи в инстаграм с разными характерами и персонами. Голосами и аватарами

> Первые соцсети - инста, общение - воцап и телеграм. Нужна воронка. Админка. Удобная понятная стильная минималистичная

SIM является личным проектом, не ITSTEP. Бриф определяет несколько самостоятельных персонажей, Instagram как первый источник контактов, WhatsApp и Telegram для общения, воронку и понятную минималистичную админку.

## Текущая продуктовая конкретизация из репозитория
Репозиторий связывает воронку с регистрацией и первой оплатой у RCIPM. Это содержание repo-документации, а не дословная часть приведённого пользовательского брифа. Начальные персонажи: Марина Светлова и Ева Коган.

Воронка: first_contact → engaged → needs_identified → interested → handed_to_partner → registered → paid. Отдельные статусы: active, paused, no_response, refused. ИИ не подтверждает оплату: последние два этапа устанавливаются по данным партнёра.

## База текущего состояния

База main после PR #1–#13, включая админку. Статусы ниже описывают код,
не факт выкладки или работы внешних каналов. Публикации Instagram по умолчанию выключены;
в этой работе флаги и production не менялись.

## Матрица возможностей
| Область | Статус | Что подтверждено |
|---|---|---|
| Разные персонажи | Реализовано в коде | Описание, ограничения, язык, модель, стратегия; начальные персонажи |
| Аватары | Частично | Поле avatar_url и отображение; генерация и production-контент не проверены |
| Индивидуальные голоса | Реализовано в коде | Google Gemini TTS через Broker `/v1/speech`, режимы off/mirror/always, отправка голосовых в Telegram (бот и аккаунт) и WhatsApp, откат в текст ([voice.md](voice.md)); маршрут Broker и scope `llm:speech` на production не активированы, видео Vivix нет |
| Кружочки ИИ | Реализовано в коде | Генерация через Broker `/v1/video/jobs` (Gemini Omni Flash), кеш по хешу запроса, отправка только на один аккаунт из настройки владельца после сообщения «Сгенерировано ИИ» ([video-notes.md](video-notes.md)); на живом ключе и в Telegram не проверено, качество русской и украинской речи не подтверждено |
| Входящие голосовые | Реализовано в коде | Загрузка и транскрипция через Broker; внешнее выполнение не проверено |
| Instagram диалоги | Реализовано в коде | instagrapi, polling, входящие запросы и личные сообщения |
| Instagram публикации | Ограниченный выключенный пилот | Один локальный JPEG, два gate, явный post ID; долговечный intent/receipt, без автоматического retry неизвестного исхода; полноценный upload/UI и live-проверка отсутствуют |
| WhatsApp | Реализовано в коде | Evolution API, linked-device QR; неофициальный транспорт с риском блокировки |
| Telegram | Реализовано в коде | Bot API и Telethon user account; реальные сессии не проверены |
| Воронка и партнёр | Реализовано в коде | Этапы, HMAC webhook, CSV; строки без ID и даты отклоняются, повтор ключа пропускается; прежние дубли не исправляются |
| Админка | Реализовано в текущей ветке | React + shadcn/ui (до этого Angular Material), inbox, клиенты, аналитика, настройки; единая переписка и фильтруемые журналы сообщений/ИИ. Проверки — в задаче админки |
| Контролер ответов | Реализовано с ограничением | Проверка, rewrite/block; известная одинаковая fallback-модель блокируется, но missing ID, aliases и self-rewrite остаются ограничениями |
| Симуляции | Реализовано в коде | Отдельные ветки в боте входа и read-only просмотр owner+ |
| История ИИ и очередь | Исправлено в коде | Только доставленные исходящие в истории; rolling pool до четырёх job, generation/CAS состояния job; отдельный intent/receipt отправки, без exactly-once гарантии |
| Финансовая аналитика | Исправлено в коде | Отдельные суммы по валютам, без FX; legacy scalar nullable. PR #9 исключает из `replied` неотправленные/blocked исходящие; порядок остаётся по `created_at` |
| Nginx login routes | Исправлено в исходниках (PR #10) | Exact locations Telegram/link; runtime и применение на сервере не проверены |
| Production | Проверен read-only 2026-11-07 | `b27a89b`, миграция `0005`, API/БД healthy; новая ветка не развёрнута, подключение реальных каналов не проверено |

## Что ещё требует решения владельца
1. Подтвердить актуальные предложение RCIPM, цены и регистрационную ссылку. В docs/personas.md они отмечены как требующие уточнения.
2. Определить критерии готовности голосов, аватаров и публикаций Instagram.
3. Выбрать ожидаемые задержки ответа и минимальный объём одновременных диалогов для нагрузочной проверки.

Валютная политика и приём CSV уже определены в [API](api.md); повторное решение владельца
для них не требуется. Доставленные исходящие в `replied` исправлены в слитом PR #9. Nginx login routes исправлены в слитом PR #10:
точные `/api/auth/telegram` и `/api/auth/link`, без ужесточения остальных auth/read routes.
Проверка сервера 2026-11-07: `nginx -t` проходит с предупреждением proxy_headers hash;
live-конфигурация ещё содержит старый `/api/auth/login`. Generation/CAS fencing слит в
PR #11, intent/receipt исходящих — в PR #12. Lease renewal и универсальная защита побочных
эффектов остаются открытыми, как и ограничения независимости guard. Старые worker нужно
полностью вывести перед rollout. Подробности: [доставка](outbound-delivery.md).
