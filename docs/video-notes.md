# Кружочки ИИ (видео-заметки персонажа, только на один аккаунт)

Владелец может попросить короткое видео персонажа, сгенерированное ИИ, и получить его
кружочком (Telegram video note) **на один разрешённый аккаунт**. Клиентам такие кружочки не
отправляются. Видео генерирует Google Gemini Omni Flash (`gemini-omni-1.2-flash`) **через
AIbroker** (`POST /v1/video/jobs`): в Sim нет ключей провайдеров.

Veo через Gemini API недоступна: Google отключил все модели Veo в Gemini API (последние
22.10.2026) и назвал заменой `gemini-omni-1.2-flash`.

## Что нужно, чтобы это заработало

1. **Broker:** проекту SIM и платному ключу gemini выдан scope `llm:video` (галочки в
   дашборде Broker). Без него Broker отвечает `403 project lacks scope: llm:video`; Sim ничего
   не отправляет и пишет эту ошибку в диалог владельца.
2. **Получатель:** в «Настройки → Кружочки ИИ → Telegram id получателя»
   (`video_note_owner_telegram_id`) указан числовой Telegram id аккаунта владельца.
   **По умолчанию 0: кружочки не создаются и не отправляются никому.** Значение хранится в БД
   (`app_setting`), `.env` не меняется.
3. **Диалог:** этот аккаунт уже писал персонажу в личку её Telegram-аккаунта (канал
   `telegram_user`). Кружочек уходит только в этот диалог; бот-каналы, WhatsApp и Instagram не
   подходят.

## Как отправить

Страница персонажа → блок «Кружочек ИИ»: описание (что в кадре и что она говорит) → «Создать
и отправить». API: `POST /api/personas/{id}/video-note` (только владелец), см. [api.md](api.md).

Дальше работает job `video_note` в воркере (`sim.services.video_note.OwnerVideoNotes`):

1. заново проверяет получателя и диалог;
2. берёт файл из кеша или генерирует клип через Broker (одна попытка: каждый клип платный);
3. ffmpeg (`sim.adapters.video.VideoNoteEncoder`) обрезает клип по центру до квадрата
   384×384, H.264 + AAC. **Звуковая дорожка клипа сохраняется как есть**: ничего не
   подмешивается, фоновый шум не добавляется;
4. ставит в очередь два сообщения в диалог владельца: текст **«Сгенерировано ИИ»** и следом
   кружочек (у кружочка в Telegram нет подписи, поэтому пометка идёт отдельным сообщением).

Статус «записывает кружочек» **не показывается**: видео сгенерировано, а не записано.

## Кеш

Один файл на запрос: хеш SHA-256 от персонажа, текста (пробелы нормализуются), длительности,
разрешения, формата кадра, референс-фото и версии кодировщика. Имя файла в медиа-хранилище —
`aivn_<40 символов хеша>.mp4`, отдельной таблицы нет.

- тот же запрос → готовый файл, Broker не вызывается, стоимость 0 (`cached: true`);
- изменился текст или параметр → новая генерация.

## Жёсткий allowlist на отправке

Проверка стоит не только при запросе, но и в SEND job (`OutboundService.ai_video_gate`): любое
исходящее сообщение, чей файл начинается с `aivn_`, кто бы его ни создал:

- не в личном диалоге `telegram_user` с разрешённым id → сообщение отменяется
  (`cancelled`), в канал ничего не уходит;
- перед ним нет доставленного сообщения «Сгенерировано ИИ» → отправка откладывается (повтор
  job), кружочек без пометки не уходит.

Если получателя сбросить в 0, уже поставленный в очередь кружочек тоже не уйдёт.

## Параметры

| Параметр | Значение |
|---|---|
| `duration_s` | 3–15 секунд, по умолчанию 5 |
| `resolution` | `360p` (по умолчанию) или `720p` |
| формат кадра | всегда 9:16 (лицо остаётся в центральной обрезке) |
| `reference_media_id` | необязательное фото из галереи этой персоны (JPEG/PNG/WebP, до 4 МБ) — как она выглядит |

Цена по прайсу Google на 2026-11 (считает и списывает Broker): около $0,023 за секунду 360p и
$0,07 за секунду 720p; клип 5 с 360p ≈ $0,12. Бесплатного тарифа у модели нет.
`SIM_BROKER_VIDEO_BUDGET_S` (900 с) — сколько воркер ждёт клип от Broker.

## Ошибки

Отказ Broker (нет scope, нет платного ключа, бюджет, отклонённый промпт) или сбой ffmpeg не
повторяются автоматически. В диалоге владельца появляется неотправленное сообщение
«[кружочек ИИ не создан]» с текстом ошибки. Отказ до генерации (получатель не задан, нет
диалога, плохой референс) API возвращает сразу как `409`; блок «Кружочек ИИ» показывает текст
причины из ответа (`detail`), а не общий текст ошибки 409.

## Что не проверено вживую

- Маршрут Broker `/v1/video/jobs` написан по опубликованной документации Google и на живом
  ключе не проверялся (ключи есть только на сервере Broker).
- **Русская и украинская речь и липсинк.** Документация Google: полностью поддерживается
  только английский, остальные языки «не оценивались, результат может отличаться»; про
  качество липсинка в документации нет ничего. Качество на русском и украинском нужно
  оценить первым реальным кружочком; заранее его никто не гарантирует.
- Отправка кружочка в Telegram проверена только тестами с фейковым транспортом.

Видео содержит невидимый водяной знак Google SynthID.
